# Pet Connect 🐾

A full-stack Pet Adoption platform built with the MERN stack.

## 🔗 Live Demo

- **Website:** [https://pet-connect-rosy.vercel.app](https://pet-connect-rosy.vercel.app)
- **Backend API:** [https://pet-connect-backend-89fo.onrender.com](https://pet-connect-backend-89fo.onrender.com)

## ✨ Features

- User Authentication (Register / Login / Logout)
- JWT Protected Routes
- Add, Edit, and Delete Pets
- Image Upload (Cloudinary)
- Smart Search & Filters (Category, Breed, Location)
- User Profile + Edit Profile
- Real-time Chat with Socket.io
- Inbox for conversations
- Responsive Design (Mobile + Desktop)
- Toast Notifications & Form Validation

## 🛠️ Tech Stack

**Frontend:**
- React (Vite)
- Tailwind CSS
- React Router
- Axios
- Socket.io Client
- React Hot Toast

**Backend:**
- Node.js
- Express.js
- MongoDB + Mongoose
- Socket.io
- JWT + bcrypt
- Cloudinary
- Multer
